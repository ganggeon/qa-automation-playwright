# 지원자 작성 산출물

이 폴더는 **지원자 본인이 작성·구성한 QA 산출물**을 모아 둔 곳입니다.
그 안에서 제공받아 활용한 부분(Postman 단언 예시, 조건 목록의 예시 3줄)은 해당 문서에 그대로 표시해 두었습니다.
저장소의 나머지 대부분(테스트 대상 MiniShop, 요구사항 명세, `artifacts/`의 참고 산출물, 학습 문서, 자동화 스위트, CI)은
**AI 도구로 구성한 학습 환경**입니다. 두 출처를 섞지 않기 위해 폴더를 나눴습니다.

| | 이 폴더 (`portfolio-submissions/`) | `artifacts/` |
|---|---|---|
| 작성 | **지원자 본인** | AI (참고 산출물 · 대조용) |
| 성격 | 명세만 보고 설계하고, 참고 답안과 대조해 보완한 결과 | 학습 환경과 함께 제공된 완성본 |

### Postman 컬렉션을 실행하려면

```bash
npm run sut                                   # SUT 기동 (http://localhost:4010)
npx newman run portfolio-submissions/postman/MiniShop.postman_collection.json \
  -e portfolio-submissions/postman/local.postman_environment.json
```

- 환경 파일의 `baseUrl`은 `http://localhost:4010`입니다. 로그인 응답의 토큰을 변수로 받아 다음 요청에 전달합니다.
- SUT를 **새로 기동한 직후**(장바구니가 빈 상태)를 전제로 합니다. 앞선 실행이 남아 있으면 금액이 달라집니다.
- 단언 코드 자체는 제공받은 예시를 활용했고, **컬렉션 구성과 401 케이스 추가**가 본인 작업입니다.
- 포트폴리오에 적은 `66,000 / 6,600 / 59,400원`은 **작성 당시 요청 전에 손으로 계산해 응답과 대조한 값**입니다.
  현재 컬렉션의 단언이 이 세 금액을 각각 고정 기대값으로 검사하는 것은 아닙니다.
- 저장소 루트의 `postman/`은 AI가 구성한 **대표 Smoke/재현 컬렉션**(14요청 · 28검증)으로 이 폴더의 것과 다른 파일이고,
  `npm run newman`과 CI가 실행하는 대상은 **그쪽**입니다. 이 폴더의 컬렉션은 CI 검증 대상이 아닙니다.

## 틀렸다가 고친 것

설계 과정에서 판단이 틀렸다가 명세를 다시 읽고 고친 사례입니다. 결과만이 아니라 **무엇을 근거로 바꿨는지**가 남아 있습니다.

**쿠폰 최소주문금액 경계값 (FR-09-3)** — 주문금액이 최소금액에 1원 모자랄 때(29,999원)의 기대 결과를
처음에는 **"쿠폰 할인만 미적용되고 정가로 결제된다"** 고 적었습니다.
명세의 **결정표 R5**를 다시 보니 그 경우는 결제가 진행되는 것이 아니라 **400 `COUPON_MIN_AMOUNT`로 주문 자체가 거부**됩니다.
"쿠폰이 안 먹는다"와 "주문이 거부된다"는 사용자에게 완전히 다른 결과인데, 규칙을 문장으로만 읽고 결정표를 대조하지 않아 생긴 오류였습니다. (2026-09-14 정정)

> 이 정정은 재검토 과정에서 확인한 것이며, 설계 당시 스스로 알아챈 것은 아닙니다.

## 이 폴더를 만든 이유

저장소만 보면 어디까지가 학습 환경이고 어디부터가 본인 작업인지 구분되지 않습니다.
**AI가 한 일을 본인이 했다고 쓰지 않는 것**이 이 저장소의 원칙이라, 출처가 다른 산출물을 물리적으로 분리했습니다.
AI가 수행한 범위는 저장소 루트 [README](../README.md)에 그대로 적혀 있습니다.
